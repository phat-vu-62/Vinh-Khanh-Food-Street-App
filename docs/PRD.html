Chapter 01

Actors & Phân quyền Hệ Thống

Hệ thống chia làm 3 Role cốt lõi với sự kiểm soát chặt chẽ qua Token JWT và Database Entity CmsDbContext.

🛡️ System Admin

Quản trị toàn quyền thông qua CMS Blazor Server.

  • Duyệt / Từ chối mở gian hàng của Owner.
  • Sử dụng tính năng Gemini AI tự động sinh bản dịch 5 ngôn ngữ.
  • Quản lý Users, khóa tài khoản và theo dõi biểu đồ Doanh thu Nền tảng.
  • Khởi tạo mã QR tĩnh truy xuất nhanh O2O.

🏪 Owner (Chủ quán)

Nhà kinh doanh đăng ký điểm bán ẩm thực.

  • Truy cập /api/auth/register-merchant đăng ký công khai.
  • Chỉnh sửa thông tin Tọa độ / Thuộc tính Audio của chính mình.
  • Thống kê Lượt truy cập / Lượt phát Audio tại Quán qua Dashboard riêng.
  • Trải qua luồng thanh toán Khơi tạo (Backend tự động ghi có Audit Log UserHistories).

🧳 Tourist (Khách Du Lịch / EndUser)

Khám phá bản đồ trực tiếp trên Mobile App Native MAUI.

  • Bắt buộc Auth Đăng nhập khi mở App để theo dõi phiên (Tracking chống lạm dụng).
  • Xem Bản đồ, quét GPS tự động và nghe Thuyết minh (TTS).
  • Quét QR Code từ Owner -> Deep Linking mở App tức thì.
  • Tự do thay đổi cục diện 5 ngôn ngữ (Language Selector rẽ nhánh Culture).

Chapter 02

Mobile App — .NET 9/10 MAUI (Kiến trúc Native)

Giao diện người dùng hướng Map-First, đồng bộ tương tác Real-time giữa SQLite Cache và Tracking API CMS.

  • Mandatory Startup Login: Hủy bỏ Popup rườm rà ở trang con (Details), dời Trạm kiểm soát Đăng nhập qua lớp Shell ngay từ đầu. Hủy luôn Offline-first của Visitor.
  • Thread-Safe Localization (.xaml): Xử lý lỗi Crash do Conflict Thread UI Ngôn ngữ đa luồng. Dùng Translation Key chuẩn hóa Single-Quotes. Hỗ trợ 5 ngôn ngữ.
  • QR Code O2O Deep Linking: Giải mã scheme URI foodstreet://poi?id=... đẩy thẳng lệnh chạy Audio TTS bypass GPS Geofence Check. Tránh giật lag khi rà GPS phố chật hẹp.

Chapter 04

GPS Geofencing + Auto Narration Defense

Việc tải GPS không chỉ là xác định vị trí, mà là thuật toán chống Spam lặp âm thanh vòng lặp kinh điển trong ứng dụng phố đi bộ hẹp m ngang.

Block Spam 15m (Minimum Spacing Guard): Thay vì dùng mốc đồng hồ (Cooldown Timer 2 phút) vô nghĩa dễ làm khách đi xe đạp rớt trải nghiệm, dự án sử dụng vòng chặn khoảng cách Haversine. Khách phải đi chuyển TỐI THIỂU 15m so với điểm cũ, Trình Geofence mới phá khóa chặn cấp phát Audio. Đảm bảo âm thanh êm ái ở Phố Vĩnh Khánh san sát quán nhậu.

Chapter 05

Hệ Điều Phối Âm Thanh (Hybrid 2-Tier Fallback)

Giải bài toán trải nghiệm thính giác mượt mà 5 Ngôn Ngữ không gián đoạn.

Tier 1: Audio Gốc Tải Sẵn (File Tín Hiệu)

Nạp MP3 trực tiếp qua Base Native. Đọc cờ AudioUrlMp3. Xử lý chuẩn nhất với giọng thu phòng thu do chủ gian hàng bồi đắp. Trọng số ưu tiên cao nhất.

Tier 2: System Text-To-Speech OS (Dynamic)

Nếu Data trống AudioUrl, bật cờ UseTts = True. App gọi hàm SpeakWithTtsAsync() mượn gói giọng đọc đa chiều của Android/iOS (Locale Code Native) để đọc tức thời dữ liệu sinh từ Gemini AI.

Tier 3: English Fallback Rescue

Trường hợp HĐH không cài đặt gói âm bản địa (Ví dụ thiết bị nội địa thiếu Text Engine Tiếng Nhật/Tiếng Hàn), Catch Exception bắt lỗi -> Tự rơi xuống Engine mặc định tiếng Anh (en-US) đọc đè tạm thời.
